# ActionForge 简体中文

适用于桌面版 Chrome 和 Edge 的 ActionForge 汉化扩展。安装后，[ActionForge](https://actionforge.app/) 的编辑器、素材库、时间轴、骨骼控件、动作实验室和导出菜单会显示简体中文。内置动作显示中英文对照，可以继续用英文名搜索。

**[下载安装包 ActionForge-ZH.zip](https://github.com/caoyusi002/ActionForge-ZH/releases/latest/download/ActionForge-ZH.zip)**

## 安装

1. 下载并解压 ZIP，保存解压出的 `ActionForge-ZH` 文件夹。
2. 在 Chrome 地址栏打开 `chrome://extensions`。Edge 使用 `edge://extensions`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的 `ActionForge-ZH` 文件夹。
4. 打开或刷新 ActionForge。安装成功后请保留该文件夹，浏览器会直接从中读取扩展。
5. 如需切换语言，点击浏览器工具栏的扩展图标，打开「ActionForge 简体中文」，勾选或取消勾选「使用简体中文」。

## 使用

在右侧「素材库 → 动画」搜索 `Death01`，点击「倒地死亡 01 · Death01」即可加载动作。可用空格播放或暂停，也可以通过顶部「导出」菜单下载 GLB。显示语言的切换会保留当前动作和原始导出名称。

这是一个第三方扩展，仅在 `actionforge.app` 生效，使用浏览器的本地存储保存语言设置。帮助文档、社区内容、部分长篇说明和画布内绘制的文字可能保留英文。
